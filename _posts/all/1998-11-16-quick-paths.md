Whenever you want a file, you first have to find the folder it is in, which is a faff if that folder is nested several levels deep. Quick Paths lives in the system tray and jumps you to a favourite folder with one click: into the topmost file selector, into Explorer, or into ZipMagic's Archive Manager. If none of those are open, it launches a new Explorer window. About 56k of RAM.

This is the sort of thing Windows later grew for itself. In 1998 you had to write it.

Version 1.38: support for Windows 98's new-style Explorer. Unregistered limit is three paths.

Featured in PC Answers issue 48, Winter 1997 (Future Publishing, UK), and in Windows Magazine (ASCII, Japan) December 1996, with a screenshot. Also on Hot Shareware (Hobby Press, Spain) several times as it went from 1.31 to 1.35.
