An icon library for Atari ST emulation under Windows 95. 32×32 and 16×16, 16-colour icons for use with PaCifiST (and later bundled with Fuji Bar!). A `.reg` file assigns the right icons to TOS programs and `.st` / `.msa` disk images if you copy the library into `C:\Windows\`.

Archived page: [gingerbeardman.com/archive/tektonix/icons.htm](https://www.gingerbeardman.com/archive/tektonix/icons.htm)
