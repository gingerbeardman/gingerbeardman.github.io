WINotes is a Post-it-style sticky notepad for the Windows desktop. Multiple notes at once, each with its own size, colour and typeface; sticky or not; load and save (optionally as plain text); file association; spawn another note; load back from the previous session; optional on-screen hotkeys; choice of alarm sound.

Version 1.73. 16-bit and 32-bit. Recompiled with Visual Basic 5 (SP3). Exit menu removed (use the close box). Load-back and Windows 98 behaviour improved.

Earlier 1.6x builds were featured on TECH Win (ASCII, Japan) and Hot Shareware (Hobby Press, Spain).
