REview is a small ASCII file viewer for the Atari ST, written in GFA BASIC 3.5. It exists because the desktop's built-in Show is not enough once you have a stack of coverdisk docs and want to search, bookmark, or print a paragraph.

Find and repeat-find, ten bookmarks, goto line, block start/end, print block or whole document, toggle scan rate, and a 24-line display with an info line for filename, page, and size. Not as good as Revenge, but not as big either.
