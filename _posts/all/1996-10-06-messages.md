Messages is a small utility for leaving notes for other people who use the same PC. Handy if you are sharing a machine with Windows 95's multi-user password facility. It manages multiple message files and uses Notepad to edit them.

Version 1.11, 16-bit and 32-bit builds. Visual Basic. Windows 3.1x and 95/NT.
