Tektonix Menu 2 is a tiny, fully customisable menu system for MS-DOS. It uses less than 8k of memory when fully utilised, which makes it ideal for launching games and other memory-hungry DOS programs. Works in a Windows 95 DOS box too.

Version 2.01. Also in the zip: a mouse prompt helper, a PCX viewer, a reboot utility, and a small DOS paint tool.
