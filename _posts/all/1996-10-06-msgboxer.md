MsgBoxer generates Visual Basic `MsgBox` code to your exact specification. Pick the icon, buttons, default button and modality in a dialog, hit Test, then paste the snippet into your app from the clipboard. Now with context-sensitive help.

Version 1.11b, 16-bit and 32-bit. Windows 3.1x and 95/NT.

This is a tool I wrote because I was tired of looking up the MsgBox flags in the help file every time.

Archived page: [gingerbeardman.com/archive/tektonix/msgboxer.htm](https://www.gingerbeardman.com/archive/tektonix/msgboxer.htm)
