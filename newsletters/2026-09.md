**2UP**

This is my Mac-Assed dual-pane file manager that works more like "Twin Finder". I use it every day and it makes managing files a pleasure. It strives to bring the Mac experience to the dual-pane file manager world. 

It has been finished for ages, after 105(!) TestFlight builds, and took about a month of back-and-forth with App Store review to get it approved. I was asked to remove the words "Finder" and "Mac" from the app's store page metadata, and was also asked if files are sent to my server…when the app had no network entitlements/permission.

LAUNCH SALE: until 14th September 2026!

[gingerbeardman.com/apps/2up/](https://www.gingerbeardman.com/apps/2up/)

**SNES DEV GAME JAM**

I'm continuing with a game called SUPER WILD CART for SNES DEV Game Jam 2026, which is running August through October. It's kinda Excite Truck × Flicky × Donkey Kong's Crash Course, but it might look more like Uniracers or Excite Bike to you. 

The interesting thing about the toolchain used for this game: I wrote the game in Lua/Love2D with a small library of 8-bit maths functions, then transpiled it to C and hooked it up with a SNES SDK. Yet with only a little massaging that runs quick enough on SNES! What a time to be alive. Thank you llvm-mos!

[blog.gingerbeardman.com/2026/08/31/transcompilation-express/](https://blog.gingerbeardman.com/2026/08/31/transcompilation-express/)
